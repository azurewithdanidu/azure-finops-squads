## Packaged contract

The maintained [capability map](../plugins/finops-squad/skills/finops-squad/references/capability-map.md)
travels with the installed plugin. It distinguishes npm-server tools from host-integrated ARM
capabilities. Installing the plugin does not establish that every host supplies those capabilities.

The [historical tool inventory](mcp-tool-inventory.md) records an earlier environment, not a
current installation test. Discover tools in the target client before making compatibility claims.
