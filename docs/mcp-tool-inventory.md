Generated by enumerating the **actual** tools reported, not assumptions. Updated 2026-10-14 after
live testing against a real subscription surfaced a command group (`arm`) not present in the
original Phase 0 enumeration.

| Item | Value |
|---|---|
| Initial capture | 2026-10-13, not signed in — `npx @azure/mcp@latest tools list` (404 tools) |
| Live-verification pass | 2026-10-14, signed in (`az login`) — direct tool calls in a Copilot/VS Code agent session |

> Both the `@azure/mcp` npm server and the host-integrated Azure tools used in this project are

> correction and live evidence.

## 1b. Host-integrated `arm` tool group (live-verified 2026-10-14)

**Not part of `@azure/mcp`.** This command group appeared directly in the Copilot/VS Code agent
session's tool list (alongside `compute`, `storage`, `monitor`, etc.) without any `.vscode/mcp.json`
entry for it. It is the real backend for cost querying, Resource Graph, and retail pricing — the
capability the original plan assumed would need a separate "ARM MCP (CostManagement)" server.
**Portability across hosts is unverified** — see the caveat in
[mcp-capability-map.md](./mcp-capability-map.md).

| Tool (command) | Access | Purpose | Live-verified? |
|---|---|---|---|
| `query_costs` | readonly | Cost by service/RG/resource/meter; `Cost`/`CostUSD`/`AmortizedCost`; daily/monthly grain; max 5 `groupBy` dims (no tags); ~92-day lookback cap; max 5000 rows | ✅ Yes — real USD figures by service and by day |
| `query_aks_costs` | readonly | AKS cost by Cluster/Namespace/UtilizationBucket/ServiceCategory, subscription scope only | Schema only — no AKS resources to test against |
| `execute_query` | readonly | Resource Graph KQL execution, with pagination via `skipToken` | ✅ Yes — matched the `az graph` CLI fallback result exactly |
| `generate_query` | readonly | Generate a Resource Graph KQL query from a natural-language prompt | Not exercised |
| `validate_query` | readonly | Validate KQL syntax before executing | Not exercised |
| `get_retail_prices` | readonly | Azure Retail Prices API lookup by service/SKU/region/meter/price type | Schema confirmed; retail REST API used directly as well |
| `get_resource_type_schema` | readonly | JSON schema for an ARM resource type + API version | Not exercised |
| `list_resource_and_action_types` | readonly | Available resource types + actions for a provider | Not exercised |
| `start_pricesheet_download` / `get_pricesheet_status` | readonly | Async download of the billing-scope pricesheet (potential source of **actual** negotiated rates, not just retail) | Not exercised — worth testing for `price-basis-handling` (EA/MCA actual rates) |
| `create_or_update_resource_group`, `create_or_update_resource`, `create_deployment`, `cancel_deployment`, `whatif_deployment` | **MUTATING** | ARM deployment management | **Never called by this project** — finops-squad is read-only; the Implementer only edits Bicep files and opens PRs |

## 3. Minimum Azure roles

**Confirmed live** against a real subscription with `az login` on 2026-10-14 — `query_costs`
succeeded with the signed-in user's existing role assignment (no extra role grant was needed beyond
what was already present).

| Role | Needed for |
|---|---|
| **Reader** | Inventory, VMs, disks, public IPs, metrics, Advisor, Resource Graph (`arm.execute_query`) |
| **Cost Management Reader** | Spend (`arm.query_costs`, `arm.query_aks_costs`) |
| **Monitoring Reader** | Azure Monitor metrics/logs utilization |

All tools used by this project are **read-only**. No agent uses any mutating Azure MCP tool
(e.g. `compute vm create/delete/update/power-state`, `*/create`, `*/delete`) or any mutating `arm`
tool (`create_deployment`, `create_or_update_resource`, etc.); all change flows through pull
requests only.
